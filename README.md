# PHÉNOMÈNES — version 2

Cette version utilise l’icône fournie et contient six œuvres : interférences multitouch, champ électrostatique, attracteur de Lorenz, gravité au gyroscope, fleur sonore au microphone et vitrail chromatique à la caméra.

## Confidentialité

Le microphone et la caméra ne sont utilisés qu’en direct dans le navigateur. Aucun son, aucune photo et aucune donnée de capteur ne sont enregistrés ou transmis. Les flux sont arrêtés en quittant l’œuvre concernée.

## Tester sur ordinateur

`index.html` permet de voir les œuvres de base. Pour tester les autorisations, le mode hors ligne et l’installation, publie les fichiers en HTTPS, par exemple gratuitement avec GitHub Pages.

## Installer sur téléphone

- Android : ouvrir l’adresse dans Chrome puis choisir `Installer l’application`.
- iPhone/iPad : ouvrir dans Safari, `Partager`, puis `Sur l’écran d’accueil`.

## Publication gratuite avec GitHub Pages

1. Crée un dépôt GitHub.
2. Copie le contenu de ce dossier à la racine.
3. Ouvre `Settings > Pages`.
4. Choisis `Deploy from a branch`, branche `main`, dossier `/ (root)`.
5. Ouvre l’adresse fournie depuis le téléphone.

Les accès caméra, microphone et gyroscope exigent généralement une adresse HTTPS.
