# PHÉNOMÈNES — version 3

Cette version pousse davantage le mélange entre science et art.

## Œuvres

1. **Résonance** — constellations d’étoiles émettant des ondes lumineuses, avec un observateur mobile.
2. **Invisible** — filtre artistique modulant quels rayons solaires traversent une membrane sélective.
3. **Coriolis** — ferrofluide coloré passant de bassin en bassin dans un monde en rotation.
4. **Pesanteur** — toile d’espace-temps, Terre et comètes à transformer en étoiles filantes sans collision.
5. **Floraison** — fleur construite par assemblage des fréquences sonores.
6. **Chromatique** — vitrail issu de la caméra, avec résolution réglable.

## Vie privée

- le microphone est demandé seulement pour **Floraison** ;
- la caméra est demandée seulement pour **Chromatique** ;
- ils sont **coupés automatiquement dès que l’on quitte l’œuvre** ;
- **aucun son, aucune image, aucune vidéo issue des capteurs n’est enregistrée ni envoyée** ;
- seul un **export PNG local** est proposé quand tu appuies sur le bouton d’enregistrement.

## Capteurs optionnels

L’orientation du téléphone peut enrichir **Coriolis** et **Pesanteur**, mais toutes les œuvres restent utilisables au doigt.

## Publication

La publication gratuite avec GitHub Pages fonctionne comme sur la version précédente.
Pour accéder à la caméra, au microphone et à l’installation complète, il faut utiliser une URL HTTPS.
